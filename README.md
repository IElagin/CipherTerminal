# Терминал шифрования

Учебная мини-игра: повторите показанную последовательность символов без ошибок.

## Запуск

1. Откройте проект в **Unity 6000.5.8f1**.
2. Откройте сцену `Assets/_Project/Scenes/GameEntryPoint.unity`.
3. В окне **Game** включите **VSync (Game view only)** для снижения нагрузки Editor.
4. Нажмите **Play**.

## Управление

- **1** — режим цифр, **2** — режим латинских букв. Можно нажать на карточку мышью.
- **3** или карточка «Движение» — лаборатория персонажей.
- Введите показанную последовательность. Регистр букв не важен; для букв используйте английскую раскладку.
- Золото, победы и поражения постоянно видны в меню.
- **4** или кнопка «Сбросить» открывает подтверждение. Списание происходит только по нажатию «Сбросить за 25 золота»; **Esc**, «Отмена» или клик вне окна отменяет действие.
- После победы **Пробел** возвращает в меню.
- После ошибки **Пробел** запускает новую попытку в том же режиме.

В игре верхний ряд показывает заданную последовательность, нижний — фактический ввод, включая первый ошибочный символ. Введённый пробел отображается знаком ␣. Результаты и ошибки сохранения видны в интерфейсе.

При первом запуске выдаётся 100 золота. Победа приносит 10, поражение снимает до 5 без ухода в минус. Сброс статистики стоит 25 и не восстанавливает стартовое золото. Прогресс сохраняется локально между запусками.

## Лаборатория персонажей

Домашние задания L4–L6. На сцене герой, враг и телепортёр (фиолетовый куб).

- **WASD / стрелки** — бег героя; бег прерывает атаку.
- **Мышь / трекпад** (движение курсора по окну Game) или **Q / E** — поворот стоящего героя.
- **Клик** — выстрел снарядом; пока идёт атака, герой не поворачивается.
- **1** — ИИ телепортёра: каждые 2 с случайный телепорт, если хватает энергии.
- **2** — ИИ телепортёра: каждые 3 с прыжок к цели с наименьшим HP в пределах радиуса; при энергии ниже 40% ждёт восстановления.
- **T** — телепорт куба в случайную точку с уроном по области.
- **Пробел** — урон телепортёру.
- **Esc** или кнопка «В меню» — возврат к терминалу.

Урон, HP и энергия выводятся в Console. Лаборатория не изменяет золото, статистику и сохранения.

## Проект

Интерфейс — uGUI/TMP, базовое разрешение 1920×1080. Настройки последовательностей, экономики и звуков находятся в `Assets/_Project/Resources/Configs`, корень UI и окна — в `Assets/_Project/Resources/UI`, вложенные элементы — в `Assets/_Project/Prefabs/UI`. Главное меню и игровой экран создаются программно при загрузке своей сцены; редактировать их нужно в Prefab Mode. Экраны используют пары View/Presenter; анимация popup — DOTween 1.3.030.
