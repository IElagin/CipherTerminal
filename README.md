# Терминал шифрования

Учебная мини-игра: повторите показанную последовательность символов без ошибок.

## Запуск

1. Откройте проект в **Unity 6000.5.8f1**.
2. Откройте сцену `Assets/_Project/Scenes/GameEntryPoint.unity`.
3. В окне **Game** включите **VSync (Game view only)** для снижения нагрузки Editor.
4. Нажмите **Play**.

## Управление

- **1** — режим цифр, **2** — режим латинских букв. Можно нажать на карточку мышью.
- Введите показанную последовательность. Регистр букв не важен; для букв используйте английскую раскладку.
- В меню **3** или кнопка «Статистика» раскрывает и сворачивает статистику; **Esc** закрывает её. При раскрытии данные также выводятся в Console.
- В раскрытой панели **4** или кнопка сброса обнуляет победы и поражения за указанную цену.
- После победы **Пробел** возвращает в меню.
- После ошибки **Пробел** запускает новую попытку в том же режиме.

Последовательность, результат и отказ при нехватке золота также выводятся в Console.

При первом запуске выдаётся 100 золота. Победа приносит 10, поражение снимает до 5 без ухода в минус. Сброс статистики стоит 25 и не восстанавливает стартовое золото. Прогресс сохраняется локально между запусками.

## Проект

Интерфейс — uGUI/TMP, базовое разрешение 1920×1080. Настройки последовательностей, экономики и звуков находятся в `Assets/_Project/Resources/Configs`, редактируемые экраны — в `Assets/_Project/Prefabs/UI`.
