# Терминал шифрования

Учебная мини-игра: повторите показанную последовательность символов без ошибок.

## Запуск

1. Откройте проект в **Unity 6000.5.8f1**.
2. Откройте сцену `Assets/_Project/Scenes/GameEntryPoint.unity`.
3. В окне **Game** включите **VSync (Game view only)** для снижения нагрузки Editor.
4. Нажмите **Play**.

## Управление

- **1** — режим цифр, **2** — режим латинских букв. Можно нажать на карточку мышью.
- **3** или карточка «Движение» — отдельная лаборатория персонажей из ДЗ L4 и L5.
- Введите показанную последовательность. Регистр букв не важен; для букв используйте английскую раскладку.
- Золото, победы и поражения постоянно видны в меню.
- **4** или кнопка «Сбросить» открывает подтверждение. Списание происходит только по нажатию «Сбросить за 25 золота»; **Esc**, «Отмена» или клик вне окна отменяет действие.
- После победы **Пробел** возвращает в меню.
- После ошибки **Пробел** запускает новую попытку в том же режиме.

В игре верхний ряд показывает заданную последовательность, нижний — фактический ввод, включая первый ошибочный символ. Введённый пробел отображается знаком ␣. Результаты и ошибки сохранения видны в интерфейсе.

При первом запуске выдаётся 100 золота. Победа приносит 10, поражение снимает до 5 без ухода в минус. Сброс статистики стоит 25 и не восстанавливает стартовое золото. Прогресс сохраняется локально между запусками.

## Домашнее задание L4

Из главного меню откройте «Движение». На отдельной сцене `MovementLab` находятся два персонажа-дроида:

- Враг (синий акцент) — движение и поворот через **Rigidbody**, обновление в `FixedUpdate`. Пока стоит на месте.
- Герой (оранжевый акцент) — движение через **CharacterController**, поворот через **Transform**, обновление в `Update`.

**WASD / стрелки** управляют героем. **Esc** или кнопка «В меню» возвращает к терминалу. Лаборатория не изменяет золото, статистику и сохранения.

Обе реализации используют общие компоненты направления и скорости, различается набор обрабатывающих их систем. Ядро и фабрика находятся в `Assets/_Project/Develop/Runtime/Gameplay/EntitiesCore`, механики — в `Gameplay/Features/MovementFeature`, сценовая композиция — в `Gameplay/MovementLab`. Параметры и пути prefab берутся из `HeroConfig` / `EnemiesListConfig`; персонажи создаются из `Resources/Entities`.

3D-модели дроидов с анимациями покоя, ходьбы и падения подключены внутри `ViewContainer` prefab; физический корень и коллайдеры остались прежними. Анимацию переключает `CharacterAnimationSystem` по `IsMoving` и `IsDead`.

## Домашнее задание L5

В той же лаборатории появился **телепортёр** — фиолетовый куб, собранный из компонентов и систем:

- имеет 100 HP; после смерти выключает коллайдеры и через 1 с удаляется сам;
- как призрак не сталкивается с персонажами (слой `Characters`, у коллайдера исключён слой `Characters`);
- не двигается и не поворачивается — в его рецепте нет компонентов и систем движения;
- имеет 100 энергии; телепорт стоит **X = 25**;
- телепортируется в случайную точку в радиусе **N = 6** от точки появления;
- после телепорта однократно наносит **D = 30** урона всем сущностям в радиусе **M = 2.5**, кроме себя; зона урона кратко подсвечивается;
- раз в **Z = 2 с** восстанавливает 10% от максимума энергии.

Герой и враг получили 100 HP и тот же жизненный цикл, поэтому тоже получают урон по области и умирают.

Управление:

- **T** — телепорт (при нехватке энергии в Console выводится отказ);
- **Пробел** — 50 урона телепортёру; два нажатия его уничтожают.

Ход проверки виден в Console: энергия после телепорта и восстановления, число целей урона и `Я получил урон 30, HP: 70` у задетых персонажей.

Рецепт — `EntitiesFactory.CreateTeleporter`, значения заданы в нём. Механики — в `Gameplay/Features`: `Energy`, `Teleport`, `AreaDamage`, а также перенесённые из курса `ApplyDamage` и `LifeCycle`. Компоненты каждой механики лежат в её `<Feature>Components.cs`. Поиск сущности по коллайдеру — `EntitiesCore/CollidersRegistryService`. Сервисы сущностей регистрируются в `MovementLabContextRegistrations`.

Генератор API Entity и дополнительное задание генерации номеров/масок слоёв находятся в `Assets/_Project/Develop/Editor`. Они запускаются при загрузке скриптов и через **Tools → Gameplay → Generate Entity API / Generate Unity Layers**. Результаты: `Gameplay/EntitiesCore/Generated/EntityAPI.cs` и `Utilities/Layers/UnityLayers.cs`.

## Проект

Интерфейс — uGUI/TMP, базовое разрешение 1920×1080. Настройки последовательностей, экономики и звуков находятся в `Assets/_Project/Resources/Configs`, корень UI и окна — в `Assets/_Project/Resources/UI`, вложенные элементы — в `Assets/_Project/Prefabs/UI`. Главное меню и игровой экран создаются программно при загрузке своей сцены; редактировать их нужно в Prefab Mode. Экраны используют пары View/Presenter; анимация popup — DOTween 1.3.030.
